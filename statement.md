Problem Statement:
Universities need an efficient way to maintain and monitor student attendance. Manually recording attendance and calculating attendance percentages can be time-consuming and may lead to errors.
The Simple University Attendance System provides a basic computerized solution for storing student details, marking students as present or absent, and calculating and displaying their attendance percentage. 
Scope of the Project:
The scope of this project is to provide a simple, menu-driven system for managing student attendance. The system allows users to- 
Add students using their roll number and name. 
Mark a student as Present or Absent. 
View the attendance details of an individual student. 
View attendance information for all registered students. 
Automatically calculate attendance percentages. 
Store student attendance information during program execution. 
The current project is designed as a basic Python application and does not include a database or graphical user interface.
Target Users:
The main target users of this system are- 
Teachers/Faculty: To record and monitor student attendance. 
College/University Staff: To maintain basic attendance records. 
Students: To check their attendance status and percentage. 
Academic Institutions: As a simple attendance-management solution for small classes or academic projects. 
High-Level Features:
Add Student – Allows the user to register a student using a roll number and name. 
Mark Attendance – Records whether a student is present or absent using P or A. 
View Student Attendance – Displays a student's name, roll number, present count, absent count, and attendance percentage. 
View All Students – Displays attendance information for all students registered in the system. 
Attendance Percentage Calculation – Automatically calculates the percentage using the number of classes attended and total classes. 
Input Validation – Handles invalid attendance input and informs the user when a student is not found. 
Menu-Driven Interface – Provides a simple numbered menu for accessing the different functions of the system.
